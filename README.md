# DrupalJira

## Requirements

- Docker
- DDEV

## Project setup

Clone the repository:

```bash
git clone <repository-url>
cd drupal-jira
```

Start the environment:

```bash
ddev start
```

Install Composer dependencies (required on a fresh clone):

```bash
ddev composer install
```

Open the site:

https://drupal-jira.ddev.site

## Stop the environment

```bash
ddev stop
```
